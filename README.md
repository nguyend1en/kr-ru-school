# Онлайн-школа «Слово» 

Учебный многостраничный сайт онлайн-школы русского языка для иностранных студентов «Слово» (каталог услуг) на Bootstrap 5.3.
В репозитории — итоговая версия контрольной работы №3 (адаптивная вёрстка и аудит доступности) и начало контрольной работы №4 (подключение JavaScript).

Сайт на GitHub Pages: <https://nguyend1en.github.io/kr-ru-school/>

## Структура проекта

```
index.html        главная: hero, ближайшие старты, преимущества, популярные курсы, шаги, призыв к тесту
catalog.html      каталог курсов с фильтром по уровню и модальным окном записи на пробное занятие
product.html      страница курса; курс выбирается параметром ?id= (a1, a2, b1, b2, club, trki2)
order.html        форма записи; курс подставляется из ?course=, ниже формы считается стоимость
test.html         пошаговый тест на уровень: 20 вопросов, результат и разбор ошибок
teachers.html     преподаватели
contacts.html     контакты, интерактивная карта Яндекса, форма обратной связи
css/custom.css    собственные стили поверх Bootstrap (переменные бренда, блоки, адаптивность)
js/data.js        данные: объект school и массив объектов courses (КР4)
js/main.js        функции КР4 и сценарии страниц
js/map.js         карта Яндекса (только на contacts.html)
js/test-data.js   вопросы теста
js/test.js        логика теста (только на test.html)
images/           favicon.svg, обложки курсов 480/960 px в WebP и JPEG
```

## Что сделано в этой версии

### Оформление: «школьная тетрадь»
Дизайн построен на образах, знакомых каждому, кто учит русский язык:
- **бумага в клетку** — фон первого экрана, обложки курсов и лист теста;
- **синяя шариковая ручка** (`#1f3b8c`) — основной цвет текста-акцентов, ссылок и кнопок;
- **красная ручка преподавателя** (`#c8102e`) — красное поле тетради, подчёркивание текущего пункта меню, исправления;
- **ударения в заголовках** («Говори́те по‑ру́сски уве́ренно») — как в учебниках РКИ;
- главный элемент первого экрана — карточка с ошибками, исправленными от руки («в Москва → в Москве́»);
- шрифты: Golos Text (кириллический гротеск) для текста и заголовков, Caveat — только для пометок «от руки» (исправления, номера шагов, оценка в тесте);
- карточки без теней и градиентов: тонкая рамка, один радиус скругления; блоки «Как мы учим» и «Контакты» — колонки с линией сверху, без иконок;
- **footer на всех страницах**: описание школы, ссылки «Обучение» и «Школа», контакты в `<address>`, соцсети, копирайт.

### Доведены до конца функции, которые были сделаны не полностью
- раньше кнопка «Подробнее» у любого курса вела на страницу курса A1. Теперь `product.html?id=…` показывает нужный курс: название, описание, цену, статус, программу и расписание групп из `data.js`;
- у курса B1 был бейдж «Скидка 10%», но цена показывалась без скидки. Теперь цена со скидкой считается функцией `getDiscountPrice()`, старая цена зачёркнута;
- со страницы курса «Записаться» открывает `order.html?course=…` с уже выбранным курсом; под списком курсов выводится стоимость;
- для закрытого курса (ТРКИ-2) кнопка записи неактивна, выводится дата следующего потока;
- всплывающее уведомление после отправки формы обращается к пользователю по имени (текст выводится через `textContent`).

### Тест на уровень (переделан)
- 20 вопросов в четырёх разделах: грамматика (8), лексика (5), чтение текста (4), диалоги (3); уровни A1–B2; данные — в `js/test-data.js`, логика — в `js/test.js`;
- вопросы по одному на экране: шкала прогресса из клеток, «Вопрос N из 20», кнопки «Назад» и «Следующий вопрос»; без выбранного ответа дальше не перейти (сообщение и фокус на варианты);
- варианты ответа перемешиваются при каждом прохождении;
- результат: примерный уровень (засчитывается, если верно ≥ 60 % вопросов уровня и всех уровней ниже), таблицы «по разделам» и «по уровням», рекомендация курса с кнопкой записи, **разбор каждой ошибки** с правильным ответом и пояснением;
- последний результат сохраняется в `localStorage` и показывается на стартовом экране;
- доступность: каждый вопрос — `fieldset` + `legend`, варианты — настоящие `radio` с `label`, после смены экрана фокус переходит на лист теста; без JavaScript показывается подсказка `<noscript>`.

### Страница «Контакты» и карта Яндекса
- карточки «Адрес», «Телефон», «E-mail», «Часы работы»; ссылки `tel:` и `mailto:`;
- интерактивная карта (JavaScript API Яндекс Карт 2.1): метки офиса и станции метро, пунктирная линия пешеходного пути, балуны с адресом и часами работы; встроенные кнопки масштаба, слоёв, полноэкранного режима и геолокации;
- **управление картой**: перетаскивание мышью и пальцем, двойной щелчок; свои кнопки «−» / «+» с подписью текущего масштаба (10–19); колесо мыши масштабирует карту после щелчка по ней (чтобы не мешать прокрутке страницы); с клавиатуры — Tab на карту, затем `+` / `−` и стрелки;
- кнопки «Офис школы», «Метро «Пушкинская»», «Путь от метро» (`aria-pressed`) и ссылка на маршрут в Яндекс Картах;
- если API не загрузился (нет интернета, блокировщик, нужен ключ), показывается виджет-карта Яндекса в `<iframe>`: её тоже можно двигать и масштабировать, а кнопки «−» / «+» и «Офис / Метро / Путь» меняют её масштаб и центр;
- ключ API можно указать в константе `YANDEX_MAPS_API_KEY` в `js/map.js` (бесплатно на <https://developer.tech.yandex.ru/>);
- форма обратной связи с проверкой полей.

> Адрес «г. Москва, Учебный переулок, д. 12, офис 305», телефон и почта условные: это учебный проект.

## КР №3: адаптивность

| Что проверялось | Как сделано |
|---|---|
| Адаптивная вёрстка | сетка Bootstrap (`col-12 col-md-6 col-lg-4`), меню сворачивается в «бургер» на ширине < 992 px, на ширине < 576 px кнопки hero растягиваются на всю ширину, уменьшаются отступы и высота карты |
| Адаптивные изображения | обложки курсов в `<picture>`: `<source type="image/webp" srcset="…-480.webp 480w, …-960.webp 960w" sizes="…">` и запасной JPEG с тем же `srcset`; заданы `width`/`height` (нет сдвига макета) и `loading="lazy"`; hero — векторный SVG |
| Адаптивные формы | поля в две колонки на планшете и одну на телефоне (`col-12 col-md-6`), `input-group` для телефона и Telegram |
| Адаптивные таблицы | таблицы курса и расписания в `.table-responsive` (горизонтальная прокрутка на узком экране) |

##  аудит доступности

| Проблема | Исправление |
|---|---|
| Не было ссылки для пропуска меню | первая ссылка на каждой странице — «Перейти к основному содержимому» (видна при фокусе с клавиатуры), у `<main>` есть `id="main"` и `tabindex="-1"` |
| Выпадающее меню открывалось ссылкой `href="#"` | переключатель меню — `<button type="button">` |
| Плохо видно фокус при работе с клавиатуры | `:focus-visible` — контрастная обводка 3 px у ссылок, кнопок и полей формы |
| Вторичный текст `#6c757d` на светлом фоне — контраст на границе нормы | вторичный текст `#545b69`: 7:1. Основной текст `#1a1d24` 16:1, белый на синей кнопке 10:1, красный `#c8102e` на белом 5,9:1 (WCAG AA ≥ 4,5:1) |
| Статичные подсказки с `role="alert"` зачитывались экранным диктором как срочные | `role="alert"` оставлен только у динамического предупреждения в тесте; у статичных блоков роль убрана |
| Повторяющиеся кнопки «Подробнее» / «Записаться» без контекста | добавлен скрытый текст: «Подробнее о курсе «…»» (`.visually-hidden`) |
| Изображения | у декоративных обложек — пустой `alt=""` (название курса уже есть в заголовке карточки); у карточки с исправлениями на главной правильные фразы продублированы скрытым текстом, а рукописные исправления скрыты от диктора (`aria-hidden`) |
| Подписи полей | у каждого поля есть `<label for>`; группа «Удобное время занятий» оформлена через `<fieldset>`/`<legend>`; подсказки связаны через `aria-describedby` |
| Ошибки формы | при неверном заполнении фокус переходит на первое ошибочное поле, тексты ошибок в `.invalid-feedback` |
| Семантика | на каждой странице `header`, `nav` с `aria-label`, `main`, `footer`; один `h1`, уровни заголовков идут без пропусков; контакты в `<address>` |
| Карта | у контейнера `role="region"`, `aria-label` и `tabindex="0"`, управление с клавиатуры, подсказка связана через `aria-describedby`, адрес и путь продублированы текстом, у `iframe` есть `title` |
| Ссылки в новой вкладке | у ссылок на соцсети и Яндекс Карты — `rel="noopener"` и пометка «откроется в новой вкладке» |
| Анимации | `prefers-reduced-motion: reduce` отключает переходы |

Проверено скриптом на всех 7 страницах: один `h1`, нет пропусков уровней заголовков, у всех изображений есть `alt`, у всех полей есть подпись, нет пустых ссылок и кнопок, нет повторяющихся `id`. Первое нажатие Tab попадает на ссылку пропуска меню.

##  подключение JavaScript

- `js/data.js` и `js/main.js` подключены в `<head>` каждой страницы с атрибутом **`defer`**: скрипты загружаются параллельно с HTML и выполняются после построения DOM строго по порядку (сначала Bootstrap, потом данные, потом `main.js`);
- в `main.js` данные товара описаны отдельными переменными (`productTitle` — строка, `productPrice` — число, `productIsOpen` — логическое значение) и объектом `product`; в `data.js` все курсы — массив объектов `courses`;
- функции:
  - `formatPrice(price)` — форматирование цены `7110 → "7 110 ₽"`;
  - `getDiscountPrice(price, discount)` — цена со скидкой (арифметические операторы, проверка диапазона скидки логическими операторами);
  - `getProductStatus(item)` — статус «Набор открыт» / «Последние места» / «Мест нет» (операторы сравнения и `!`, `||`);
  - `getShortDescription(text, maxLength)` — краткое описание с обрезкой по границе слова;
- результат работы функций выводится в консоль (`console.log`, `console.table` со всеми курсами). Проверка: F12 → Console;
- учебное сообщение на главной («Каталог в цифрах») выводится через **`textContent`**.

**Почему не `innerHTML`.** `innerHTML` разбирает строку как HTML. Если в строку попадут данные пользователя (имя из формы, параметр адреса), вместе с ними на страницу можно вставить разметку или скрипт (XSS). `textContent` вставляет строку как обычный текст. В проекте `innerHTML` больше не используется: результат теста и строки таблиц собираются через `createElement` + `textContent`. Например, если ввести в поле «Имя» строку `<b>Ли</b>`, в уведомлении она появится как текст, а не как жирный шрифт.

## Функции из КР №3 (сохранены)

1. **Фильтр курсов по уровню** (`catalog.html`) — `btn-group` + `btn-check`, лишние карточки скрываются утилитой `d-none`, число найденных курсов объявляется через `aria-live`.
2. **Онлайн-тест на уровень** (`test.html`) — переделан, см. раздел «Тест на уровень».
3. **Страница преподавателей** (`teachers.html`) — карточки `card` со стажем, специализацией, языками общения и курсами.
4. **Вкладки на странице курса** (`product.html`) — «Информация о курсе», «Программа», «Расписание групп».
5. **Проверка форм и уведомление** — валидация Bootstrap (`needs-validation`, `was-validated`, `invalid-feedback`) и `toast` после отправки; теперь также на странице контактов.
